## 📌 Executive Summary

I am a Software Engineer and Computer Science undergraduate with a disciplined engineering mindset and a focus on **end-to-end full-stack architectures, high-concurrency backend services, and practical AI/RAG systems**. 

- 🏛️ **Industry Experience:** Previously engineered real-time dashboard systems and secure JWT-authenticated microservices at the **Real Time Governance Society (RTGS)**, Government of Andhra Pradesh.
- ⚙️ **Core Technical Breadth:** Proficient in designing resilient RESTful APIs, distributed job queuing architectures (atomic transactions, crash recovery, DLQs), and responsive modern frontends.
- 🧠 **Applied AI & Data:** Built production-oriented Retrieval-Augmented Generation (RAG) pipelines, semantic document query engines, and predictive ML classification pipelines.
- 🎯 **Algorithmic Rigor:** Active problem solver on LeetCode with continuous practice in Data Structures, Algorithms, and System Design principles.
